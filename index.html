Local LLM

A private, self-hosted AI assistant for personal use.

Local LLM is a personal project. It runs an open-source language model on a home server owned and operated by one person, and it is used only by that person. It is not a product or a public service, and nobody else can sign up for it.

The assistant can be given read-only access to its owner's own Google Calendar, Gmail and Google Drive so that it can answer questions such as "what is on my calendar tomorrow?". That access is used only to answer the owner's own requests.

How Google data is used

  • Access is read-only. The assistant cannot send, change or delete anything.
  • Data is fetched from Google directly to the owner's home server and processed there.
  • Nothing is sent to any other company, service or AI provider.
  • Nothing is sold, shared, or used for advertising.

Full details are in the privacy policy.
