Privacy Policy

Local LLM · Last updated October 8, 2026

Local LLM is a personal, self-hosted AI assistant. It runs on a home server owned by a single individual and is used only by that individual. It is not offered to the public.

What data is accessed

When its owner authorises it, Local LLM can read the owner's own Google account data through Google's APIs:

  • Google Calendar: calendars and events.
  • Gmail: messages and their contents.
  • Google Drive: file names and file contents.

Access is read-only. Local LLM cannot send email, or create, modify or delete any calendar event, message or file.

How the data is used

The data is used only to answer requests made by the owner, for example finding an email or listing upcoming events. It is retrieved from Google directly to the owner's home server and processed there by a language model running on that server.

Sharing and transfer

Google user data is not shared with, transferred to, or sold to anyone. It is not sent to any third-party service or external AI provider, and it is not used for advertising.

Use of data for AI models

Google user data is not used to develop, train or improve any AI or machine-learning model. It is only supplied to a locally running model at the moment a request is answered.

Storage and retention

Authorisation tokens and the owner's conversation history are stored on the owner's home server. Google data is not copied into any separate database. Conversation history can be deleted by the owner at any time.

Security

The server is reachable only from the owner's home network and private VPN. The component that talks to Google is not reachable from any other device.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, which immediately stops Local LLM from reading any Google data.

Google API Services User Data Policy

Local LLM's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the updated version will be published on this page with a new date.
